# 마스터 반 기념 STL을 활용해서 문제 풀기
----
# 1. A + B

```c++
vector<int>vtr;

int a = 0;

int b = 0;



while (cin >> a >> b) {

  vtr.push_back(a + b);

}


cout << vtr.front();



```
사용한 STL : Vector
-----
입력
첫째 줄에 A와 B가 주어진다. (0 < A, B < 10)

출력
첫째 줄에 A+B를 출력한다.

예제 입력 1 
1 2
예제 출력 1 
3

사용한 알고리즘 : 단순 연산
----
시간 복잡도
------------
```c++
while (cin >> a >> b) {
  vtr.push_back(a + b);
}
```

공간 복잡도: $O(N)$
입력을 즉시 출력하지 않고 vector에 모두 담아두기 때문에, 입력받은 $N$개의 데이터를 저장할 메모리 공간이 필요합니다.만약 백준에서 $N$ 이 매우 큰 문제라면 메모리 제한에 걸릴 수도 있지만, 일반적인 $A+B$ 문제에서는 전혀 문제없는 수준입니다.
