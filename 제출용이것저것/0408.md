# 마스터 반 기념 STL을 활용해서 문제 풀기
----
# 1. A + B

```c++
vector<int>vtr;

int a = 0;

int b = 0;



while (cin >> a >> b) {

  vtr.push_back(a + b);

}


cout << vtr.front();



```
사용한 STL : Vector
-----
https://www.acmicpc.net/problem/1000
<br>백준 1. A+B
문제
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

입력
첫째 줄에 A와 B가 주어진다. (0 < A, B < 10)

출력
첫째 줄에 A+B를 출력한다.

예제 입력 1 
1 2
예제 출력 1 
3

사용한 알고리즘 : 단순 연산
----
시간 복잡도 : $O(N)$
------------
입력값의 크기와 상관없이 단 한 번의 더하기 연산만 수행하므로 상수 시간이 소요됩니다.


공간 복잡도: $O(N)$
------
두 개의 변수(A, B) 외에 추가적인 메모리 공간을 거의 사용하지 않습니다.


풀이 되짚어보기
-----
```c++
cout << vtr.front();
```
vtr의 값을 출력하려는데 어떻게 출력할지 고민하다가 예제는 한가지만 출력했단걸 기억하고 vtr.front()로 vtr 백터의 0인덱스의 값을 출력했지만 
for문을 활용해서 예제가 주어진 만큼 출력하는쪽이 더 괜찮았을 듯 싶다.
